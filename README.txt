# Nyok Eats — Online Food Ordering System

A responsive student project built with plain HTML, CSS, and JavaScript.

## Files
- `index.html` — page structure, menu area, cart drawer, checkout form, and order confirmation.
- `style.css` — dark theme with orange accents and responsive layout.
- `script.js` — sample food data, category filters, search, cart quantity controls, price calculations, and checkout confirmation.

## How to run
1. Download and extract `online_food_ordering.zip`.
2. Open the extracted `online_food_ordering` folder.
3. Double-click `index.html` to open it in a browser.
4. For editing, open the folder in Visual Studio Code. You can optionally use the Live Server extension, but it is not required.

## How to test
1. Select a category or search for a food.
2. Click the orange `+` button on a food card.
3. Click **Your Cart** in the top-right.
4. Use `+` and `−` to change quantities, or remove an item.
5. Check the subtotal, delivery fee, and total.
6. Click **Continue to checkout**, fill out the required fields, and click **Place order**.
7. Review the local order confirmation and click **Back to menu**.

## Notes
- Prices are sample prices in Philippine pesos (PHP).
- The delivery fee is a demo flat fee of ₱49 when the cart has items.
- The checkout form validates required fields and shows a local receipt-style confirmation.
- This is a front-end demo only. It does not process real payments, contact a restaurant, store orders in a database, or send customer information to a server.
- The sample menu uses emoji illustrations, so no image downloads are needed. The Google Fonts import requires internet; the page still works with fallback fonts if offline.
